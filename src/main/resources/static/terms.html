Queue Terms & Priority-Lane Policy

Please read these rules before getting a ticket. / Basahin ang mga patakaran bago kumuha ng ticket.

  1. The priority lane is only for persons with disabilities (PWD), senior citizens, and pregnant students. / Para lamang sa mga PWD, senior citizen, at buntis na estudyante ang priority lane.

  2. Show a valid ID at the counter before service. A ticket is a queue claim, not proof of eligibility. / Ipakita sa counter ang valid ID bago asikasuhin. Katibayan lamang ng puwesto sa pila ang ticket, hindi ito patunay ng eligibility.

  3. Without a valid ID, the priority ticket is forfeited. Get a new REGULAR ticket at the kiosk; it joins the end of the line. / Kung walang valid ID, forfeited ang priority ticket. Kumuha ng bagong REGULAR ticket sa kiosk; sa dulo ito ng pila mapupunta.

  4. One ticket is for one transaction only and cannot be transferred. All transactions are logged. / Isang ticket para sa isang transaksyon lamang at hindi ito maaaring ipasa sa iba. Nila-log ang lahat ng transaksyon.

  5. Public monitors display ticket codes only and do not show personal details. / Mga ticket code lamang ang ipinapakita sa mga monitor; walang personal na detalye.
